30 NGÀY SỐNG KHỎE — BẢN CÀI TRÊN IPHONE (PWA)

CÁC FILE
- index.html: giao diện và chức năng app.
- manifest.webmanifest: tên, màu, biểu tượng và chế độ hiển thị.
- service-worker.js: lưu bộ khung app để hỗ trợ mở khi ngoại tuyến.
- icons/: các biểu tượng app.

CÀI TRÊN IPHONE
1. Tải toàn bộ file trong ZIP và giải nén trên máy tính.
2. Tạo một repository Public trên GitHub, ví dụ: 30-ngay-song-khoe.
3. Upload TẤT CẢ nội dung trong thư mục này vào thư mục gốc repository (không upload nguyên thư mục lồng bên trong).
4. Vào Settings > Pages > Build and deployment:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
   Nhấn Save.
5. Đợi GitHub Pages xuất bản, mở địa chỉ site bằng Safari trên iPhone.
6. Trong Safari, nhấn nút Share (ô vuông có mũi tên lên) > Add to Home Screen / Thêm vào Màn hình chính.
7. Nếu có lựa chọn Open as Web App / Mở dưới dạng ứng dụng, bật lựa chọn đó rồi nhấn Add / Thêm.

LƯU Ý
- Cần HTTPS; GitHub Pages cung cấp HTTPS.
- Phải mở link bằng Safari để thêm vào Màn hình chính ổn định nhất.
- Đây là web app cài lên Màn hình chính, không phải file IPA/App Store.
- Tiến độ được lưu trong trình duyệt trên thiết bị, chưa đồng bộ qua nhiều máy.
- Nếu cập nhật file sau này, đôi khi cần mở lại website có mạng để nhận phiên bản mới.
